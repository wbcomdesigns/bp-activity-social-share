# Activity Share for BuddyPress 3.6.0 - Free implementation plan

Product plan (what and why): [`3.6.0-PLAN.md`](3.6.0-PLAN.md). This file is the **how**: every task, the files it creates, its card, and the check that proves it done. Pro's tasks live in the Pro repo (`docs/plans/3.6.0-IMPLEMENTATION-PRO.md`).

Rules for every task:
- Work on branch `3.6.0`, commit locally per task, nothing pushed without owner go-ahead.
- A task is done when its **Verify** passes in the browser (Playwright MCP, screenshot looked at), not when code is written.
- Every string translatable with `bp-activity-social-share`; no inline `<script>` / `<style>`; token-only CSS; `php -l` + WPCS clean per commit.
- End of each wave: stop for owner review; after approval move the wave's cards to Ready for Testing with a verification comment.
