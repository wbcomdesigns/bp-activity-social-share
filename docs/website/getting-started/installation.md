# Installation

1. Make sure **BuddyPress** is installed and active.
2. Go to **Plugins > Add New**, search for **Activity Share for BuddyPress**, then **Install** and **Activate**.
3. That's it - every activity post now has a **Share** button.

Requirements: WordPress 6.7+, PHP 8.1+, BuddyPress.

Optional: adjust networks and looks under **WB Plugins > Activity Share**.

## Upgrading from 3.5.x

Your networks and "visitors can share" choice are moved to the new settings automatically on the first page load after the update. Old settings are then removed.

## Using Activity Share Pro

Install and activate the free plugin first, then Pro. Both always use the same version number - update them together.
