# Quick Start

This walkthrough gets the "Share" button live on your activity stream in a few minutes.

## Step 1: Confirm BuddyPress is active

The plugin loads only when BuddyPress is active. If you see a notice saying BuddyPress is required, install and activate BuddyPress first.

## Step 2: Open the settings screen

In the admin menu, go to WB Plugins, then BuddyPress Share. The screen has three tabs:

- Welcome
- General Settings
- Icon Color Settings

## Step 3: Choose which networks are enabled

Open the General Settings tab. You will see two columns, Enable and Disable. Each network you want members to use goes in the Enable column. See [Enable Social Networks](../usage/enable-social-networks.md) for the drag and drop details.

By default the plugin enables a starter set of networks on first activation, so the button already works before you change anything.

## Step 4: Decide how links open

On the General Settings tab there is an Extra Options section with an "Open as popup window" checkbox.

- Checked: share links open in a centered popup window.
- Unchecked: share links open in a new browser tab.

WhatsApp and E-mail always open directly and are never forced into a popup.

## Step 5: Set icon colors (optional)

Open the Icon Color Settings tab to pick a color for each network's icon, then save. See [Icon Colors](../usage/icon-colors.md).

## Step 6: Check the front end

Open your activity stream while logged in. Each activity now shows a "Share" button. Click it to reveal the enabled network icons. Clicking a network opens its share dialog for that activity's permalink.
