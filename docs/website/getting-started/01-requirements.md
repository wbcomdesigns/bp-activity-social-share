# Requirements

Before you install Activity Share for BuddyPress, check your site meets these requirements.

| Requirement | Minimum |
|---|---|
| WordPress | 6.7 |
| PHP | 8.1 |
| BuddyPress | Active on the site (any recent version) |

Activity Share for BuddyPress will not activate without BuddyPress active - WordPress shows this as a required plugin.

## Activity Share Pro

If you also use **Activity Share Pro**, install and activate the free plugin first, then Pro. Free and Pro always ship the same version number - always update both together. If Pro is newer than Free, Pro pauses itself and shows a one-click update notice. If Free is newer than an old Pro, Free steps back and keeps the site working until Pro is updated.

## Theme support

The share menu follows your theme's colours and dark mode automatically. It has been built and tested with **BuddyX**, **BuddyX Pro** and **Reign**, and works with most themes that use standard WordPress colour tokens. BuddyBoss Platform is supported on a best-effort basis. Youzify is not supported - it has its own sharing feature, so both plugins stay inactive while Youzify is active.
